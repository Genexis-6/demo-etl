How it maps to the code

Extract

Catalog pages fetched together with asyncio.gather; every product page and review call is a separate coroutine.

Semaphore + batches

A shared asyncio.Semaphore caps in-flight requests. Products run in batches with a pause between them to avoid bans.

Resilience

Retries with exponential backoff and jitter; HTTP 429 triggers a longer wait before the request is retried.

Transform + Load

Prices parsed to floats, text normalised, accessories removed by a query-aware regex, then bulk-inserted via SQLAlchemy.
